# MLRL03 - Final Model

Consolidated machine learning and reinforcement learning models for algorithmic trading. Final iteration combining results from MLRL01 and MLRL02.

## Overview

Integration of ML models and RL agents developed across the MLRL project series. This repository contains:

- ML models from initial experimentation (MLRL01)
- Refined RL implementations (MLRL02)  
- Web-based interface for model visualization and analysis

## Technology Stack

- **Backend**: Python
- **Frontend**: TypeScript, Next.js
- **Model Development**: Jupyter Notebooks

## Setup

```bash
npm run dev
```

Access the interface at `http://localhost:3000`

## Project Structure

```
├── MLRL01/     ML models and analysis notebooks
├── MLRL02/     Reinforcement learning implementations
└── MLRL03/     Web dashboard
```

## Development

Modify models in MLRL01 and MLRL02 directories. Frontend components are in `app/` directory.

## References

- [Next.js Documentation](https://nextjs.org/docs)
- Model-specific documentation in individual project directories
